This is an example log file recorded with a [TopDon Phoenix Max] (https://www.topdon.us/collections/diagnostic-tools/products/phoenix-max) scan tool.

You can open this file with the application in the /src directory or you can record your own with the TopDon.  I have currently only provided the ability to reliably open the ECM and TCM datalogs on a P2 Volvo XC90.  If you record a log that crashes the application, I apologize in advance.  If you want to send me a log to add functionality for, please contact me and I will do that.
